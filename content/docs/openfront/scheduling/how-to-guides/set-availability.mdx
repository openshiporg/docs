---
title: Set weekly availability
description: Create a schedule, a date override, and blocked time.
icon: Clock
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Create a schedule
At `/dashboard/platform/availability/new` choose a time zone and weekly hours.
</Step>
<Step>
### Attach it
Select the schedule on each event type.
</Step>
<Step>
### Add an override or block
Add a `date` override for special hours or a `block` for time off.
</Step>
<Step>
### Check the storefront
Open `/book/[slug]` and confirm the slots.
</Step></Steps>
