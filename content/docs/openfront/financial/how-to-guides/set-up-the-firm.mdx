---
title: Set up the firm
description: Create the administrator, run onboarding and set the firm identity.
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Initialise
Open `/dashboard/init` and create the first user, who gets the `Admin` role.
</Step>
<Step>
### Onboard
Run the onboarding dialog (`runFinancialOnboarding`). It creates settings, providers, assets, accounts and approval policies.
</Step>
<Step>
### Set identity
In Store settings enter firm name, tagline, logo, colour and currency.
</Step>
<Step>
### Add operators
Create users with only the flags they need.
</Step>
</Steps>
