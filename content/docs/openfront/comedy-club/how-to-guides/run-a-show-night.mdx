---
title: Run a show night
description: Open doors, check guests in, seat tables, run checks and close the night.
icon: MoonStar
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>

### Open Tonight

Go to **Tonight** and pick the show. Choose **Open doors**.

</Step>
<Step>

### Check guests in

Scan each ticket's QR code or type its code. Use the guest list for guests without a code.

</Step>
<Step>

### Seat parties and open checks

Seat each party at its tables, then open a check with the guest count. Add items as they are ordered.

</Step>
<Step>

### Close checks

Present and close each check. The two-item minimum per guest is added for any shortfall.

</Step>
<Step>

### Close the night

Close the show. Payouts are created for each performed slot and the settlement is written. Approve and record payouts in **Payouts**.

</Step>
</Steps>
