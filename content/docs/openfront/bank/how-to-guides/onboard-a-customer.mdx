<Steps>
<Step>

### Start

On **Customers**, start an application with the applicants and products (`startApplication`).

</Step>
<Step>

### Submit and verify

Submit it and run verification (`submitApplication`, `runVerification`).

</Step>
<Step>

### Review

Resolve any check that needs a person (`resolveVerificationCheck`) and decide (`decideApplication`).

</Step>
<Step>

### Enrol

Enrol the customer for online banking and hand over the temporary password (`enrolCustomerLogin`).

</Step>
</Steps>
