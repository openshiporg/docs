Openfront Bank serves Keystone GraphQL at `/api/graphql`. The MCP server for agents is at `/api/mcp-transport/mcp`, with read and request tools. Partner webhooks arrive at `/api/webhooks/[provider]`, and `GET /api/health` reports database reachability.

## Public operations

No GraphQL operation is public. Customers sign in, and their actions run as commands in their own session.

## Staff queries

`institutionItems`, `redirectToInit`, `verifyAuditChain`, `eodStatus`, `depositTotals`.

## Mutations by area

| Area | Mutations |
| --- | --- |
| Customers and onboarding | `startApplication`, `submitApplication`, `runVerification`, `enrolCustomerLogin`, `resolveVerificationCheck`, `decideApplication`, `withdrawApplication`, `proposeScreeningDisposition`, `revealPartyPii` |
| Accounts, products and statements | `publishProductVersion`, `openAccount`, `statementDocument` |
| Transfers, ACH and external accounts | `addPayee`, `submitTransfer`, `cancelTransfer`, `decideAchReview`, `acceptAchReturn`, `decideReceivedAch`, `createExternalLinkSession`, `linkExternalAccount`, `confirmExternalLinkOwnership`, `removeExternalAccount`, `runAchCycleNow`, `downloadAchFile`, `recordAchFileTransmission`, `recordAchReturnsTransmission`, `uploadAchInboundFile`, `runDueJobsNow`, `runDueWork` |
| BSA/AML, teller and vault | `loadSanctionsList`, `setupTellerDrawer`, `openTellerDrawer`, `closeTellerDrawer`, `requestVaultCash`, `requestFedCurrency`, `confirmVaultCash`, `previewCashTransaction`, `postTellerCash`, `draftCtrFiling`, `recordCtrFiling`, `ctrFilingXml` |
| Operations and end of day | `cutoffBusinessDayNow`, `requestForceCutoff`, `runEodNow`, `resumeEod`, `requestEodStepWaiver` |
| Institution, approvals and audit | `assignRole`, `updateStaffLimits`, `requestAgentGrant`, `revokeAgentGrant`, `setPartnerCredentials` |
| Setup and approvals | `loadInstitutionSetup`, `decideApprovalRequest`, `cancelApprovalRequest`, `requestInstitutionControls` |

Every state change takes an `idempotencyKey`. Repeating a call with the same key returns the first result.
