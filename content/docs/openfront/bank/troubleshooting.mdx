---
title: Troubleshooting
description: Common messages and fixes.
icon: LifeBuoy
---

| Message or symptom | Cause and fix |
| --- | --- |
| `BANK_SECRET_KEY is not set. Generate one with: node -e …` | Set `BANK_SECRET_KEY` to 32 bytes, base64url. |
| `BANK_SECRET_KEY_VERSION must be a positive integer.` | Set `BANK_SECRET_KEY_VERSION` to the version of the key in use, such as `2`. |
| `The secret envelope failed authentication.` | The key does not match the one that sealed the value. Restore the key or the matching version. |
| A partner production host is refused | Set `BANK_ALLOW_LIVE_PARTNERS=true` and have a second person approve go-live. |
| An ACH file stays ready to send | Send it through FedLine and record the acknowledgement. |
| A teller cash posting is refused | The day's cash is reportable. Capture the identification the CTR needs. |
