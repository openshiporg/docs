title: Troubleshooting
description: Error messages and fixes.
icon: LifeBuoy
---

| Message | Fix |
|---|---|
| A vehicle is required before deal submission | Attach a vehicle |
| Deal vehicle must be available | Pick an available unit |
| Deal status changes must use transitionDeal | Use the command |
| Lease structures require term, residual, and money factor | Fill the lease fields |
| Only submitted applications can be queued | Check the application status |
| Every menu product requires current operator/provider quote evidence | Record quotes first |
| Delivery acknowledgment is unbound or stale; record it for the current worksheet | Re-record after worksheet changes |
| A test drive can only be marked no-show after its scheduled time | Wait |
| Invoice number is required before invoicing | Add it |
| Active accounting batch already exists for source | Finish the open batch |
| Payment is already reconciled with different evidence | Use the original evidence |
| Photos changed; reload and try again | Reload |
| Inventory acquisition changed concurrently; reload and retry | Reload |
| Part inventory changed concurrently | Reload |
| Privacy acknowledgement is required. | Tick it on the form |
| Inventory intake requires an active rooftop and dealer group | Run onboarding first |
| Condition must be new, used or certified | Fix the value |
| Email verification is unavailable | Configure SMTP |
