---
title: API keys
description: Create scoped, IP-limited keys at /dashboard/platform/api-keys.
icon: Key
---

Each user manages their own `ApiKey` records: create, scope, limit by IP, revoke. Scopes: `read_inventory`, `write_inventory`, `write_leads`, `write_deals`, `write_service`, `read_reports`. Requires `canManageKeys`.
