`/dashboard/platform/overview` (`operationalReport`) shows work that needs attention today, the latest deals, and delivered revenue by month. `/dashboard/platform/analytics` shows read-only sales, inventory, and operations charts from the same report query and list reads.

Data is scoped to the rooftops you can reach. Dealer cost appears only with `canViewDealerCost`.
