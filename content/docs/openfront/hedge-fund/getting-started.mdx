## Requirements

- Node.js 20 or later
- PostgreSQL
- An Alpaca API key to trade (paper or live)

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>

### Clone and install

```bash
git clone https://github.com/openshiporg/openfront-hedge-fund.git
cd openfront-hedge-fund
npm install
```

</Step>
<Step>

### Configure `.env`

```bash
cat > .env <<'EOF'
DATABASE_URL=postgresql://...
SESSION_SECRET=<random string of 48 or more characters>
PII_ENCRYPTION_KEY=<64 hex characters>
EOF
```

| Variable | Notes |
| --- | --- |
| `DATABASE_URL` | PostgreSQL connection string. Required. |
| `SESSION_SECRET` | Signs sessions. 48 or more characters. Required. |
| `PII_ENCRYPTION_KEY` | Seals tax ids, bank details and broker API keys. 64 hex characters, required in production. Rotate with `PII_ENCRYPTION_KEY_V2`. |
| `CREDENTIAL_PEPPER` | Keys the fingerprint shown for a broker key id. Falls back to `SESSION_SECRET`. |
| `OPENROUTER_API_KEY`, `OPENROUTER_MODEL` | The model used by the dashboard assistant. |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` | Mail for password resets. |
| `PUBLIC_SIGNUPS_ALLOWED` | Allows self-signup when set. |

</Step>
<Step>

### Apply migrations and start

```bash
npm ci
npm run dev   # builds the Keystone schema, applies migrations, starts Next.js
```

</Step>
<Step>

### Create the first user

Open `/dashboard/init` and create the first admin. Its role, **Owner / Admin**, gets every permission except break-glass.

</Step>
<Step>

### Load the sample firm

Use **Set up your fund** in the sidebar to load Halvorsen Ridge Capital, a fictitious firm, in two sections. Loading is idempotent.

| Section | What it loads |
|---|---|
| Firm, people and controls | Eleven roles with separated duties, nine people, the NYSE calendar 2026-2028 and the approval policies. |
| Fund structure and shadow NAV | Halvorsen Ridge Master Fund LP (Cayman) with Class A (1.5 / 20, 5% soft hurdle) and Founders (1 / 15), the feeders Halvorsen Ridge Partners LP and Halvorsen Ridge Offshore Ltd valued by look-through, recorded closing marks, an opening portfolio and three shadow NAV runs. |

Seeded people cannot sign in until an admin sets their password or sends a reset link.

</Step>
</Steps>

## Tests

```bash
npm run verify
HF_TEST_DATABASE_URL="postgresql://…/db?schema=vitest" npx vitest run   # adds the database tests
```

Without `HF_TEST_DATABASE_URL` the database suites are skipped.
