Openfront Hedge Fund serves Keystone GraphQL at `/api/graphql`. The MCP server is at `/api/mcp-transport/mcp` for OAuth clients. Agents read through the same access rules as the user they act for, and every change is a named domain command from `features/keystone/mcp/registry.ts`. API routes serve investor statement PDFs and the Form 13F information table.

## Public operations

No operation is public. The fund home page reads the published `fund_page` piece on the server.

## Staff queries

`seriesIssues`, `firmSettingsItems`, `feeTermsVersions`, `liquidityTermsVersions`, `redirectToInit`, `verifyAuditChain`, `trialBalanceOf`, `verifyJournalChainOf`, `eligibilityOf`, `capitalReconciliationOf`, `verifyHoldingChain`, `myInvestorSummary`, `statementPdfOf`, `filingPlan`, `thirteenFInformationTable`.
