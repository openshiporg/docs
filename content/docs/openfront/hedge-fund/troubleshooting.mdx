---
title: Troubleshooting
description: Common messages and fixes.
icon: LifeBuoy
---

| Message or symptom | Cause and fix |
| --- | --- |
| A broker must be connected | The sleeve has no bound broker account. Connect Alpaca under **Brokers** and bind the account. |
| `PII_ENCRYPTION_KEY must be 64 hex characters` | Set `PII_ENCRYPTION_KEY` to 64 hex characters. |
| `Set PII_ENCRYPTION_KEY before storing tax ids or bank details` | Set `PII_ENCRYPTION_KEY` in production. |
| `MARKET_DATA_UNAVAILABLE` | The quote source has no keys. Connect the broker or the market data source. |
| Fills are not booked | Run the worker (`npm run worker`), or open **Orders** to poll fills. |
| The 13F export is refused | A held 13(f) security lacks a valid CUSIP or a mark. Fix it and export again. |
