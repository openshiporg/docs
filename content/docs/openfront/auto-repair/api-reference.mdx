Openfront Auto Repair serves Keystone GraphQL at `/api/graphql`. The MCP server for assistants is at `/api/mcp-transport/mcp`. Customer link APIs are plain HTTP routes under `/api/public/*` that take a token, never a session. PDFs are served at `/api/estimates/[id]/pdf` and `/api/invoices/[id]/pdf`.

## Public operations

No GraphQL operation is public. Online booking and "Check my repair" are server actions in `features/storefront/actions`. Customer links use the `/api/public/*` routes described on the external storefront page.

## Staff queries

`organizationSettingsItems`, `diagnosisHypotheses`, `redirectToInit`, `verifyAuditChain`, `checkAuthorizedCeiling`, `previewShopInvoice`, `shopDaySummary`, `followUpBoard`, `aiProviderStatus`, `diagnosisGate`, `supplierDisputeEmail`, `campaignPreview`, `shopReports`, `shopTieOuts`, `accountingJournalPreview`, `exportFile`.
