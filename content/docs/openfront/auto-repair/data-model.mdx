## Lifecycles

| List | Statuses |
| --- | --- |
| `Appointment` | `requested`, `confirmed`, `arrived`, `no_show`, `cancelled` |
| `RepairOrder` | `draft`, `checked_in`, `in_service`, `on_hold`, `ready_to_invoice`, `invoiced`, `closed`, `void` |
| `Job` | `draft`, `priced`, `offered`, `authorized`, `declined`, `deferred`, `in_progress`, `needs_reauthorization`, `completed`, `voided` |
| `Inspection` | `assigned`, `in_progress`, `completed`, `sent`, `reviewed` |
| `EstimateVersion` | `draft`, `sent`, `superseded` |
| `Authorization` | `recorded`, `superseded`, `revoked` |
| `Invoice` | `finalized`, `sent`, `partially_paid`, `paid`, `credited` |
| `Payment` | `initiated`, `pending`, `succeeded`, `failed`, `unknown`, `partially_refunded`, `refunded` |
| `SupplierOrder` | `draft`, `placing`, `unknown`, `placed`, `confirmed`, `partially_received`, `received`, `closed`, `cancel_requested`, `cancelled`, `failed` |
| `BusinessAccount` | `active`, `prospect`, `credit_hold`, `closed` |
| `ComebackCase` | `open`, `diagnosed`, `resolved`, `cancelled` |
| `AgentProposal` | `drafted`, `previewed`, `confirmed`, `executing`, `executed`, `rejected`, `stale`, `failed` |
| `ApprovalRequest` | `pending`, `approved`, `rejected`, `expired`, `cancelled` |

Status fields cannot be updated through the generic API. Only the named mutations move them, and each move writes an audit event.
