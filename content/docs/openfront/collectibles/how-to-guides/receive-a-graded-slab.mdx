---
title: Receive a graded slab
description: Add a PSA, BGS or CGC slab with its certificate and list it.
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Create the variant
Create a product with a `graded` variant and a SKU.
</Step>
<Step>
### Receive
Open Receive Items. Enter code, title, condition, SKU, price, grading company, grade and certificate.
</Step>
<Step>
### Publish
Tick publish, or publish later from the item record.
</Step>
</Steps>
