---
title: Set up the shop
description: Create the administrator and run the Complete card shop onboarding.
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Create the administrator
Open `/dashboard/init` on an empty database and sign in.
</Step>
<Step>
### Pick a template
Open the onboarding dialog and choose Complete card shop, Starter shop or Custom setup.
</Step>
<Step>
### Connect payments
In Payment providers add the Stripe keys and connect the provider to your region.
</Step>
<Step>
### Refresh prices
On Market & Repricing run a market refresh.
</Step>
</Steps>
