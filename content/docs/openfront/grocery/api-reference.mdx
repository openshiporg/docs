GraphQL is served at `/api/graphql`. `schema.graphql` in the repo is the reference. The playground is on outside production.

## Authentication

Dashboard and storefront sessions use the Keystone session cookie. Guest carts and guest orders use HttpOnly cookies and a signed order token. Signed-in requests read the user's current Store and capability from the database each time. Public reads use `PUBLIC_STORE_ID` and return only published products and active departments.

## Examples

```graphql
mutation Advance($orderId: ID!) {
  advanceOrderFulfillment(orderId: $orderId, target: "picking") {
    success
  }
}
```

```graphql
mutation Pick($orderId: ID!, $lineItemId: ID!) {
  resolveOrderLineFulfillment(
    orderId: $orderId
    lineItemId: $lineItemId
    resolution: "picked"
    quantity: "1.250"
    unitOfMeasure: "lb"
    idempotencyKey: "pick-1"
  ) {
    success
  }
}
```

Generated CRUD stays for lists such as `departments`, `orders`, `addresses`, `favoriteProducts`, `shoppingLists`, `subscriptions`, `products`, and `contactMessages`, under the list access rules.
