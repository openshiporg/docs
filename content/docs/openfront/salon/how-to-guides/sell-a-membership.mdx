---
title: Sell a membership or package
description: Create a plan and sell it to a client.
icon: Gift
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Create the plan
At `/dashboard/platform/benefits` create a membership (monthly price, member discount, covered services) or a package (price, savings, validity days, included services).
</Step>
<Step>
### Sell it
Pick the client, the plan, and how they paid, then Record sale. The client needs a linked account.
</Step>
<Step>
### Use it
At checkout choose the membership or package. Members get the percentage off covered services. Packages draw down their remaining value.
</Step>
<Step>
### Pause or cancel
Pause a membership with a resume date, or cancel it. Cancelled memberships cannot be reactivated.
</Step>
</Steps>
