## Lifecycles

| List | Statuses |
| --- | --- |
| `Appointment` | `requested`, `booked`, `confirmed`, `checked_in`, `in_progress`, `ready_for_checkout`, `completed`, `cancelled`, `no_show`, `declined` |
| `Client` | `prospect`, `active`, `inactive`, `merged`, `closed` |
| `Patient` | `pending`, `active`, `inactive`, `deceased`, `merged` |
| `Encounter` | `open`, `in_progress`, `pending_signature`, `signed`, `voided` |
| `ClinicalOrder` | `ordered`, `in_progress`, `completed`, `cancelled`, `reversed` |
| `Prescription` | `draft`, `active`, `exhausted`, `expired`, `cancelled` |
| `CsContainer` | `sealed`, `open`, `emptied`, `quarantined`, `disposed`, `retired` |
| `LabOrder` | `ordered`, `specimen_collected`, `sent`, `partial`, `final`, `corrected`, `reviewed`, `communicated`, `cancelled` |
| `Estimate` | `open`, `accepted`, `closed` |
| `Invoice` | `draft`, `posted`, `partially_paid`, `paid`, `written_off` |
| `Payment` | `pending`, `succeeded`, `failed`, `unknown`, `voided` |
| `Enrollment` | `pending_payment`, `active`, `cancelling`, `cancelled`, `suspended`, `completed`, `ended_by_death` |
| `BoardingReservation` | `requested`, `confirmed`, `checked_in`, `checked_out`, `cancelled`, `no_show` |
| `CallRecord` | `ringing`, `in_progress`, `completed`, `failed` |
| `ApprovalRequest` | `pending`, `approved`, `rejected`, `expired`, `cancelled` |

Status fields cannot be updated through the generic API. Only the named mutations move them, and each move writes an audit event.
