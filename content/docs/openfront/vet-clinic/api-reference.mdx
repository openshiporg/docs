Openfront Vet Clinic serves Keystone GraphQL at `/api/graphql`. The MCP server for agents is at `/api/mcp-transport/mcp`. An agent acts only through its tool grants and never inherits the permissions of the person who connected it.

## Limits

- A top-level list returns at most 500 rows. Page with `take` and `skip`.
- A nested list with no `take` returns at most 50 rows, and a few short ones return at most 10. Pass `take` (up to 500) for more.
- One request may ask for about 5,000 rows and 2,000 nested lookups in total. A request over that is refused with `QUERY_TOO_BROAD` before it runs.
- One request may sign in only once, and may check the audit chain at most twice.
- One address gets 20 sign-in attempts in 15 minutes, and 5 failures per account.

## Public operations

The client site does not use public GraphQL operations. It uses the server actions in `features/storefront/actions.ts` (`signInAction`, `registerAction`, `openTimesAction`, `bookVisitAction`, `cancelVisitAction`, `requestRefillAction`). `payByLink` and `checkLinkPayment` take a signed pay-link token instead of a session.

## Staff queries
