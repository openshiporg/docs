The schema has 41 lists in `features/keystone/models`. Generated GraphQL names come from Keystone, with a few plurals changed to avoid clashes.

## Rules

- Money is integer cents. Percentages are basis points. Each money list has a `currencyCode` (default `USD`).
- Times are instants. Local time comes from `Venue.timezone`.
- Every list has `createdAt` and `updatedAt`.
- Command-only lists block generated create, update, and delete. Catalog lists allow create and update with `canManageEvents`. Status fields are never writable through generated updates.
- Customer-visible codes are random and not sequential: `orderNumber` and `ticketCode`. Entry tokens are stored only as a SHA-256 hash in `tokenHash`.
- `AuditEvent` rows are created by commands only. They cannot be updated or deleted.
- Paid records keep a snapshot. `TicketOrderLine` stores title, level, phase, seat labels, prices, fees, tax, and quantity. An accepted `Offer` stores its terms and a hash. A `Settlement` stores its computed snapshot and a hash.

| From | To |
| --- | --- |
| `Venue` | `SeatingChart`, `Event`, `DateHold` |
| `SeatingChart` | `ChartSection`, which has `Seat` |
| `Event` | `Venue`, `SeatingChart`, `Tour`, `EventArtist`, `Offer`, `EventExpense`, `PriceLevel`, `SeatInventory`, `ProductionHold`, `InventoryHold`, `TicketOrder`, `Ticket`, `ScanEvent`, `MerchSales`, `Settlement` |
| `PriceLevel` | `ChartSection` (many), `PriceLevelPhase`, `SeatInventory` |
| `SeatInventory` | `Event`, `Seat`, `PriceLevel`. One record per seat per event |
| `InventoryHold` | `Event`, `PriceLevel`, `SeatInventory` (many), `TicketOrder`, `PromoRedemption` |
| `TicketOrder` | `Event`, `TicketOrderLine`, `Ticket`, `PaymentCollection`, `Payment`, `PromoRedemption` |
| `Ticket` | `TicketOrder`, `TicketOrderLine`, `SeatInventory`, and `transferredFrom` another `Ticket` |
| `Settlement` | `Event`, `SettlementLine`, `ArtistPayment`, and `previousVersion` another `Settlement` |
| `Offer` | `Event`, `Artist`, `EventArtist` |

## Virtual fields

`Event` has computed `sold`, `held`, `open`, `kills`, and `gross`. `sold` and `held` add up the event's price levels. `open` is capacity less sold, held, and blocked. `kills` counts killed seat records. `gross` sums paid order totals.
