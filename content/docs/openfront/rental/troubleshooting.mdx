description: Messages and fixes.

| Message or symptom | Cause and fix |
| --- | --- |
| Attach this listing to an available unit before publishing. | The listing has no unit |
| Archived listings are read-only. | Create a new listing |
| Calendar import is unavailable: `<blocker>` | Fix the connection or mapping named |
| Card payment is currently unavailable. | No card provider is enabled |
| Card payment is only available for test bookings. | Arrange payment with the host |
| Another payment is awaiting confirmation. | Wait for it or cancel the attempt |
| Assess this refund before issuing it | Decide the amount or decline |
| A refund can be reduced under the cancellation policy, not increased. | Issue a separate refund for more |
| Confirm that the external or cash refund has already been completed before reconciliation. | Tick the attestation |
| A task must be assigned before it can start. | Assign it |
| A blocked task requires a reason. | Add one |
| A stay can include at most 15 invited guests. | Remove invitees |
| An amended stay cannot exceed 730 nights. | Shorten the stay |
| A signed agreement for an active stay stays in force. | Cancel the stay first |
| Administrators cannot grant the owner role. | Only an owner can |
| Agreement link is invalid or expired. | Reissue the link |
| Reset email not offered | Set host, sender, and store link |
| Uploads fail | One of the five `S3_*` values is missing |
