Adapters live in `features/integrations/payment`.

| Code | Use |
| --- | --- |
| `pp_system_default` | Manual. A host records money already received and attests manual refunds |
| `pp_stripe_stripe` | Stripe card payments. Enabled when `STRIPE_ENABLED=true`, the keys start with `sk_` and `pk_` (test or live; mode follows the keys), and `STRIPE_WEBHOOK_SECRET` starts with `whsec_`. Once set up, every confirmed stay can be paid by card from the trip page |

Webhooks arrive at `/api/payment-webhooks/[providerCode]`. The route limits body size and read time before verifying the signature. Events are stored as `PaymentWebhookEvent`.

Guests see "Card payment is currently unavailable." when Stripe is not configured, and "Card payment isn't set up for this host" when the host has no installed Stripe provider; they arrange payment with the host.
