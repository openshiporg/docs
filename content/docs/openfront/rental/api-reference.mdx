GraphQL is served at `/api/graphql`. Public reads use exact slugs or opaque 48-character hex tokens.

## Guest queries

## hostStayCommand

`hostStayCommand(command, input)` is the entry point for most dashboard actions. It requires a signed-in user and returns `{ ok, message, data }`.

Commands: `transition`, `amend`, `reassign`, `listing_allocate`, `party_amend`, `party_invites_amend`, `payment_record_manual`, `payment_cancel_attempt`, `refund_create`, `refund_record_manual`, `refund_process`, `refund_decline`, `refund_assess`, `deposit`, `claim_create`, `claim_transition`, `agreement_void`, `agreement_reissue`, `conversation_reply`, `conversation_status`, `conversation_link_revoke`, `conversation_link_reissue`, `review_moderate`, `catalog_transition`.

Generated CRUD exists for every model; change reservation, payment, and refund state through the commands.
