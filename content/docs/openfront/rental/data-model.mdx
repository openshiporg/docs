## Relationships

| From | To |
| --- | --- |
| `Property` | address, units, owners |
| `Listing` | `Property`, `AccommodationUnit`, media, rate plans, calendar blocks, reservations, reviews |
| `Reservation` | `Listing`, unit, `GuestProfile`, `StayQuote`, payments, refunds, agreement, deposits |
| `Payment` | `Reservation`, `PaymentProvider`, refunds, deposits, webhook events |
| `OwnerStatement` | owner, lines, payouts |

Every host-scoped list carries a `hostOrganization`. Quotes and line items keep snapshots of accepted values.
