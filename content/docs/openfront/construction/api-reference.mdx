Defined in `features/keystone/mutations/index.ts`. Every command checks the session or API key, permission, company, project, expected state, reason where required, and idempotency key.

## Payments

Queries and mutations: `constructionPayableClaims(projectId)`, `createCustomerPayment(requestId)`, `reconcileCustomerPayment(requestId, sessionId)`, `createClaimPayment(projectId, claimId)`, `createClaimPaymentLink(projectId, claimId)`, `checkPaymentStatus(projectId, paymentId)`, `installStripePaymentProvider(companyId)`, `setPaymentProviderInstalled(providerId, isInstalled)`.

## Lifecycle transitions

Every `transition<Type>Status` takes a target status and a reason of 3 to 500 characters.
