---
title: Troubleshooting
description: Common messages and fixes.
icon: LifeBuoy
---

| Message or symptom | Cause and fix |
| --- | --- |
| `Token secret must be at least 32 bytes. Set SESSION_SECRET.` | Set `SESSION_SECRET`, or the purpose secret, to at least 32 bytes. |
| `The card processor key on this server is not a Stripe secret key.` | Set `STRIPE_SECRET_KEY` to an `sk_` or `rk_` key. |
| `Unknown action.` | The `op` passed to `clinicalCommand` or `billingCommand` does not exist. |
| A closed census day refuses a change | Signed-off days are closed. Use a census correction, which needs approval. |
| A card payment is `unknown` | Check its status (`payment.check_status`). The processor is asked again with the same key. |
| Public forms refuse requests behind a proxy | Set `TRUSTED_PROXY_HOPS=1` so rate limits see the real address. |
