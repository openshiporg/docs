## GraphQL (`/api/graphql`)

Operator session with verified two-factor. Query size, depth, and alias limits apply, with a 256 KB body cap. Most lists are read-only; changes use named mutations.

Queries: `redirectToInit`, `operatorSessionAssured`, `fullStraightSettlementPlan`.
