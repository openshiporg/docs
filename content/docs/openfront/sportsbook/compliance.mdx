| Review | Lists | Actions |

| AML | `AMLCase`, `ScreeningHit` | `reviewAMLCase`, `recordComplianceScreening` |
| Location | `GeoSession`, `GeoCheck` | read |
| Affordability | `AffordabilityAssessment` | read |
| Privacy | `CustomerPrivacyRequest` | `transitionPrivacyRequest` |
| Integrity | `IntegrityCase` | opened from a wager with `openWagerInvestigation` |

Customer verification at registration writes `PlayerIdentity`, `VerificationCase`, and checks, approving when the entered age meets the configured minimum (default 18).
