title: Build a catalog and open a market
description: Create an event, price it, and open the market.
icon: Trophy
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Reference data
At `/dashboard/platform/catalog/reference` add the sport, competition, season, and competitors.
</Step>
<Step>
### Create the event
At `/dashboard/platform/catalog` create the event with its first market.
</Step>
<Step>
### Price it
Open the market in Trading and set prices for every selection.
</Step>
<Step>
### Open it
Set the market `OPEN`. It appears on the board.
</Step></Steps>
