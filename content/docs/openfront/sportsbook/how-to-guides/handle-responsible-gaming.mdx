title: Set limits or exclude a player
description: Apply a limit or self-exclusion.
icon: HeartPulse
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Open the player
At Responsible gaming find the player.
</Step>
<Step>
### Apply
Set a limit with `setResponsibleGamingLimit`, or record a self-exclusion.
</Step>
<Step>
### Confirm
New wagers from that player are refused while the limit or exclusion applies.
</Step></Steps>
