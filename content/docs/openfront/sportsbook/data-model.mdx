Defined in `features/keystone/models` (`Sportsbook.ts`, `SportsbookFull.ts`, `SportsbookP0.ts`, `Customer.ts`, `User.ts`, `Role.ts`). The source repo's `docs/schema-map.md` lists every list. `Tenant` is the operator boundary; nearly every list has a `tenant` relation and PostgreSQL row-level security uses `app.tenant_id`.

| Domain | Lists |
|---|---|
| Operator | `Tenant`, `Brand`, `BrandLocale`, `LegalEntity`, `Jurisdiction`, `OperatorJurisdiction`, `OperatorLicence`, `JurisdictionPolicyVersion`, `OperatorChannel`, `CurrencyDefinition`, `TenantCurrency`, `OnboardingProgress` |
| Catalog | `Region`, `Sport`, `Competition`, `Season`, `CompetitionStage`, `Venue`, `Competitor`, `Event`, `EventParticipant`, `EventScheduleChange`, `MarketDefinition` |
| Configuration | `ConfigDefinition`, `ConfigValue`, `FeatureFlag`, `HouseRuleVersion`, `TaxRuleVersion`, `RetentionPolicyVersion` |
| Trading and risk | `Market`, `Selection`, `PriceSnapshot`, `TradingStatusChange`, `TraderOverride`, `FeedHealthSnapshot`, `LimitProfile`, `LimitRule`, `CorrelationGroup`, `CorrelationRule`, `ExposurePosition`, `WagerExposureAllocation` |
| Wagering | `BetSlip`, `BetSlipItem`, `Quote`, `CustomerQuoteTerms`, `CustomerQuoteLegTerms`, `AcceptanceDecision`, `Wager`, `WagerLeg`, `WagerPart`, `WagerStatusEvent`, `CashOutOffer`, `CashOutAcceptance` |
| Results | `ResultVersion`, `MarketGrade`, `LegGrade`, `SettlementRun`, `Settlement`, `SettlementLine`, `ResettlementCase` |
| Finance | `LedgerAccount`, `JournalTransaction`, `JournalEntry`, `BalanceProjection`, `Hold`, `PaymentIntent`, `PaymentAttempt`, `LedgerAdjustmentRequest`, `ReconciliationRun`, `ReconciliationItem`, `SafeguardingAccount`, `SafeguardingReconciliation`, `TaxAssessment` |

| Compliance | `VerificationCase`, `VerificationCheck`, `GeoSession`, `GeoCheck`, `AMLCase`, `ScreeningHit`, `AffordabilityAssessment`, `IntegrityCase`, `CustomerPrivacyRequest`, `AccountRestriction`, `PlayerLimit`, `SelfExclusion` |

| Integrations and ops | `ProviderConnection`, `ProviderHealthSample`, `ProviderEntityMapping`, `AdapterCertificationRun`, `TradingReplayRun`, `RawEnvelope`, `InboxMessage`, `OutboxMessage`, `WebhookEndpoint`, `WebhookDelivery`, `IntegrationDeliveryAttempt`, `WebhookReplay`, `DeadLetter`, `ScheduledJob`, `WorkerHeartbeat`, `Incident`, `ApiRateBucket` |

Money is integer minor units in text fields with a currency code.
