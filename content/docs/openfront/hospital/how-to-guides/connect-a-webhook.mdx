---
title: Connect an inbound webhook
description: Let a payment processor or claims system report results back to the app.
icon: Webhook
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Prepare
Set `INTEGRATION_SECRET_ENCRYPTION_KEY` (64 hex characters). It encrypts each installation's signing secret.
</Step>
<Step>
### Install
On the integrations tab of `/dashboard/platform/operational-fabric`, add an installation of kind `payment` (payment and refund results) or `webhook` (claim results). Copy the one-time signing secret.
</Step>
<Step>
### Issue a credential
Issue a machine credential for the installation with the `webhook:write` scope. Copy the `ofh_…` value; it is shown once.
</Step>
<Step>
### Send events
POST JSON with `eventId`, `eventType`, and `aggregateId` to `/api/integrations/{installationKey}/webhook`. Send the credential as `Authorization: Bearer ofh_…`, a Unix-seconds `x-openfront-timestamp`, and `x-openfront-signature`: the hex HMAC-SHA256 of `timestamp.body` under the signing secret.
</Step>
<Step>
### Check receipts
Requests more than 5 minutes off, replays, and events the installation kind does not accept are refused. Each accepted event is stored as an `IntegrationWebhookReceipt`.
</Step>
</Steps>
