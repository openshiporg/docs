## Key relationships

| From | To |
| --- | --- |
| `Facility` | departments, providers, staff, patients, appointments, encounters |
| `Appointment` | `Patient`, `Provider`, `AppointmentType`, `Facility`, intake forms, queue tickets |
| `Encounter` | patient, provider, department, appointment; orders, results, claims |
| `Admission` | patient, encounter, bed, attending provider |
| `InsuranceClaim` | patient, encounter, coverage, `ClaimVersion` |

## Controlled records

Controlled lists omit GraphQL create, update, and delete. Each row carries a `transitionVersion`, an `operationKeyHash`, and a `requestHash`, so repeated calls are idempotent and stale ones are rejected.
