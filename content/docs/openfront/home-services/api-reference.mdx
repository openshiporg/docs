Openfront Home Services serves Keystone GraphQL at `/api/graphql`. The MCP server for agents is at `/api/mcp-transport/mcp`. Agent reads are masked, and each write needs a grant for that exact tool. Document and export routes live under `app/api`, including accounting exports, cancellation notices, estimates, membership renewals, pay periods, purchase orders, the refrigerant log, reports, stock and warranty.

## Public operations

No GraphQL operation is public. The storefront uses the server actions in `features/storefront/actions.ts` (`checkZip`, `loadWindows`, `confirmBooking`, `startInvoicePayment`, `openByCode`).

## Staff queries

`companySettingsItems`, `mediaItems`, `redirectToInit`, `verifyAuditChain`, `resolvePolicy`, `availableWindows`, `lookupCustomer`, `customerHistory`, `lookupLocations`, `matchJobType`, `checkEligibility`, `searchPriceBook`, `quotePriceBook`, `priceBookVersionReview`, `estimateSummary`, `agentBindings`.
