## Lifecycles

| List | Statuses |
| --- | --- |
| `Lead` | `new`, `contacted`, `qualified`, `booked`, `converted`, `lost`, `spam`, `merged` |
| `Call` | `ringing`, `ai_answering`, `human_answering`, `handoff_requested`, `completed` |
| `Job` | `draft`, `booked`, `scheduled`, `in_progress`, `on_hold`, `work_complete`, `awaiting_inspection`, `completed`, `closed`, `cancelled` |
| `Visit` | `unassigned`, `scheduled`, `dispatched`, `en_route`, `on_site`, `working`, `paused`, `done`, `cancelled`, `no_access` |
| `Estimate` | `open`, `sold`, `declined`, `expired`, `cancelled`, `discarded` |
| `CancellationNotice` | `issued`, `delivered`, `waived`, `cancelled_by_buyer`, `expired_uncancelled`, `refunded` |
| `Invoice` | `draft`, `posted`, `partially_paid`, `paid`, `written_off`, `voided`, `discarded` |
| `PaymentAttempt` | `pending`, `succeeded`, `failed`, `unknown` |
| `Membership` | `pending_payment`, `active`, `past_due`, `suspended`, `renewal_due`, `expired`, `cancelled`, `transferred` |
| `WarrantyClaim` | `draft`, `ready`, `submitted`, `info_requested`, `approved`, `partially_approved`, `denied`, `settled`, `closed` |
| `PurchaseOrder` | `draft`, `pending_approval`, `approved`, `sent`, `acknowledged`, `partially_received`, `received`, `billed`, `closed`, `cancelled` |
| `Permit` | `needed`, `applied`, `issued`, `closed`, `not_required`, `rejected` |
| `Timesheet` | `open`, `submitted`, `approved`, `locked` |
| `PayPeriod` | `open`, `calculating`, `review`, `approved`, `exported`, `closed` |
| `ApprovalRequest` | `pending`, `approved`, `rejected`, `expired`, `cancelled` |

Status fields cannot be updated through the generic API. Only the named mutations move them, and each move writes an audit event.
