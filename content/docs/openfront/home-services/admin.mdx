**Agents** sets each agent's grants and autonomy, has a kill switch, and lists actions for review. **Approvals** lists requests waiting for a second person. **Tasks** holds work queues such as follow-ups, overdue registrations and exceptions. **Audit log** shows the hash-chained events and checks the chain. **Settings** holds the company, licences, branches, business units, calendars and approval policies.

## Pages

| Page | Route | What it shows |
| --- | --- | --- |
| Agents | `/dashboard/platform/agents` | Agent grants, autonomy, kill switch and action review. |
| Approvals | `/dashboard/platform/approvals` | Maker-checker requests waiting for a second person. |
| Tasks | `/dashboard/platform/tasks` | Work queues: follow-ups, overdue registrations, exceptions. |
| Audit log | `/dashboard/platform/audit` | Hash-chained audit events and chain verification. |
| Settings | `/dashboard/platform/settings` | Company, licences, branches, business units, calendars and approval policies. |

## Commands

Named mutations for this area. Each checks permissions on the server, takes an idempotency key and writes an audit event.

`refreshTimedStates`, `bindAgentApp`, `unbindAgentApp`.
