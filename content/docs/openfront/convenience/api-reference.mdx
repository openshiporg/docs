Declared in `features/keystone/mutations/index.ts`. Every mutation takes an input object with `businessId`, usually `storeId`, and an `idempotencyKey`; it returns `OperationResult`. Money is integer cents.

## Queries

 `storefrontCatalog`, `storefrontBasket`, `storefrontHistory`, `storefrontRewards`, `conveniencePublicStorefront`, `conveniencePlatformProjection`, `conveniencePlatformNavigation`, `convenienceReportingSummary`, `posSaleReceipt`, `posOperationOutcome`, `downloadExportArtifact`, `assistantCapability`, `redirectToInit`.

## Example: open a drawer

```graphql
mutation {
  openRegisterSession(input: {
    businessId: "..."  storeId: "..."  registerId: "..."
    employeeId: "..."  openingCashCents: 20000
    idempotencyKey: "open-reg1-2026-10-30"
  }) { __typename }
}
```

## Key inputs

- `completePosSale`: `cartId`, `tenders[]` (`method`, `amountCents`, `tenderedCents`, `paymentProviderId`, `providerPaymentId`, `providerAuthority`, `cardBrand`, `cardLast4`)
- `refundPosSale`: `saleId`, `registerSessionId`, `employeeId`, `reason`, `lines[]`, `tenderAllocations[]`, `managerPin`
- `receivePurchaseOrder`: `purchaseOrderId`, `locationId`, `employeeId`, `lines[]`
- `startInventoryCount`: `locationId`, `type`, `variantIds`
