`/dashboard/platform/products` and `/products/[id]` show variants, barcodes, photos, prices, stock by location, vendor items, and recent movements.

## Create or edit an item

`configureCatalogItem` creates or edits a product, variant, barcode, category, and tax category together.

| Field | Notes |
|---|---|
| `title`, `handle`, `description`, `status` | |
| `regulatedSaleType` | none, alcohol, tobacco, lottery, otc_medicine, other |
| `minimumAge` | Required for restricted types. "Minimum age must be empty for an unrestricted product" |
| `preparedFood`, `discountable`, `returnable` | |
| `taxCategoryId`, `categoryName` with `categoryCode` | Provide the category pair together |
| `variantTitle`, `sku`, `sellBy`, `unitOfMeasure` | |
| `defaultPriceCents`, `costCents` | integer cents |
| `trackInventory`, `allowNegativeStock` | |

Photos are `ProductImage` rows stored in S3.
