Signal checks look for work (an unverified coverage, a claim waiting too long, an open chair) and the assistant turns them into proposals. A proposal waits for a person unless an autonomy policy the practice set allows that kind of action. Separate permissions decide claim, clinical and financial proposals.

**Calls** connects a Twilio phone number for the voice receptionist and keeps a manual call log for calls handled by staff.

## Commands

Named mutations for this area. Each checks permissions on the server, takes an idempotency key and writes an audit event.

`runSignalChecks`, `setAutonomyPolicy`, `decideProposal`, `setVoicePolicy`, `logManualCall`, `markCallFollowedUp`, `connectPhoneNumber`, `disconnectPhoneNumber`.
