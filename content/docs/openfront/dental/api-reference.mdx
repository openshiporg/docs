Openfront Dental serves Keystone GraphQL at `/api/graphql`. The MCP server for agents is at `/api/mcp-transport/mcp` and uses OAuth clients (`OAuthApp`, `OAuthToken`). Agents read through the same access rules as the user they act for, and every change they make is a named command, never generic create, update or delete.

Generic list queries and mutations exist for every list. Status fields are read-only through them.

## Public operations

`publicSite`, `publicAvailability`, `publicChat`, `publicHoldSlot` and `publicSubmitBooking` need no session. Portal operations (`portalRequestCode`, `portalSession`, `portalMe`, `portalAppointments`, `portalConfirm`, `portalCancel`, `portalReschedule`, `portalPreferences`) use the `x-portal-token` header.

## Staff queries

`practiceSettingsItems`, `redirectToInit`, `verifyAuditChain`, `mfaStatus`, `findAvailability`, `publicSite`, `aiHome`, `voiceConnections`, `publicChat`, `publicAvailability`, `portalMe`, `portalAppointments`.
