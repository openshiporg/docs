`StoreSettings` is a singleton. There is one record per deployment. It controls how the restaurant looks to guests and how money, time, and ordering rules behave. Edit it at `/dashboard/platform/store-settings`. Saving needs `canManageSettings`.

## What lives in store settings

- name, tagline, logo icon and logo color, address, phone, and email
- currency code, locale, timezone, and country code
- weekly opening hours
- tax rate
- delivery on or off, delivery postal code allowlist, delivery fee, and delivery minimum
- pickup discount percent
- estimated pickup and delivery times (display text)
- hero headline, subheadline, tagline, and promo banner
- rating and review count for display (the rating is only shown when the review count is positive)
- a read-only `paymentProviders` field that lists configured providers and their public keys

Inside the hours setting, the page also stores ordering controls:

- **Ordering cutoff minutes before closing**: stop new orders this many minutes before close (0 to 240).
- **Maximum active online orders**: 0 means no limit.
- **Menu service windows**: open and close times for breakfast, lunch, and dinner, in venue-local time.

## Where it is used

- storefront hero, banner, logo, footer contact details, and hours
- open or closed status and the ordering cutoff
- meal period checks on menu items and categories
- currency and locale formatting in the storefront, POS, and reports
- tax, delivery fee, delivery minimum, and pickup discount in checkout and POS totals
- delivery address checks (country and postal code allowlist)
- online order capacity

When an order is created, the pricing settings are frozen onto it. Later changes do not reprice open orders. Checks with different frozen pricing cannot be merged.

## Delivery rules

New settings have delivery off and an empty allowlist. Turning delivery on requires a country code and a postal code allowlist. The server rejects an inconsistent setup.

## Recommended setup order

<Steps>
<Step>
### Identity
Set name, tagline, logo, address, phone, and email.
</Step>
<Step>
### Localization
Set currency, locale, timezone, and country before testing prices and reports.
</Step>
<Step>
### Hours and ordering limits
Set weekly hours, the cutoff, the online order limit, and meal windows.
</Step>
<Step>
### Ordering money
Set tax rate, pickup discount, and, if you deliver, the delivery allowlist, fee, and minimum.
</Step>
<Step>
### Check the storefront
Open the home page and checkout to confirm the settings show up.
</Step>
</Steps>
