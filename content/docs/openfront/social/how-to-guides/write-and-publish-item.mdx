---
title: Write and publish an item
description: Draft an item and publish a version.
icon: FileText
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Create
At `/dashboard/platform/library/create` choose a collection, type, and title.
</Step>
<Step>
### Write
Add summary and markdown body, and set the occurred-at date.
</Step>
<Step>
### Publish
Press Publish. The item appears at `/<handle>/<collection>/<slug>` if the collection is public or unlisted.
</Step>
<Step>
### Change it later
Edit and publish again for a new version, or unpublish to return it to draft.
</Step></Steps>
