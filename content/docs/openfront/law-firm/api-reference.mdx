---
title: GraphQL API
description: Endpoint rules and custom queries and mutations.
icon: Code
---

`/api/graphql` accepts POST only, JSON or same-origin multipart. Bodies are capped at 1 MB; uploads at 10 MB and 5 files. Lists return at most 100 items. Depth is limited and introspection is off. Bearer API keys, OAuth tokens, and agent credentials are accepted.

## Queries

| Group | Queries |
| --- | --- |
| Public and customer | `consultationCatalog`, `consultationCatalogPage`, `consultationService`, `consultationAvailability`, `customerConsultations`, `customerConsultationPage`, `customerConsultation`, `portalSharedResource` |
| Staff | `practiceOverview`, `practiceWorkspace(category)`, `previewContactImport`, `portalPolicyWorkspace` |
| Viewer | `viewerCanAccessDashboard`, `viewerCanRunConflictChecks`, `viewerCanResolveConflicts`, `viewerNeedsFirmOnboarding` |

Money and access mutations take an idempotency key, run in a serializable transaction under an advisory lock, and write an `AuditEvent`.

## Other routes

`/api/oauth/authorize`, `/api/oauth/token`, `/api/payment-webhooks/[providerId]`, `/api/health`, `/api/completion`. `/api/mcp-transport/http` returns 501.
