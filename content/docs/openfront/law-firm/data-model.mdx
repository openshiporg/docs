## Tenancy

Every firm-owned list has a `firm` relationship. Shared hooks assign the active firm on create and reject links to another firm's records.

## Append-only

Document versions, trust entries, matter status events, signature events, audit events, and agent action events are append-only.

## Lifecycles

| Record | Path |
| --- | --- |
| Intake | `new` → `screening` → `conflict_review` → `consultation` → `decision` → `converted`, `declined`, `withdrawn` |
| Conflict check | `requested` → `running` → `review_required` → `cleared`, `conflict_found` |
| Matter | `proposed` → `pending_conflict` → `open`, `on_hold`, `closing`, `closed`; `declined` |
| Consultation | `requested` → `scheduled` → `completed`, `cancelled`, `no_show` |
| Invoice | `draft` → `approved` → `issued` → `partially_paid` → `paid`; `overdue`, `void` |
| Refund | `requested` → `approved` → `processing` → `succeeded`, `failed` |
