---
title: Set up an ethical wall
description: Block users from a matter.
icon: ShieldAlert
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>

### Create
On the matter workspace add a wall with a reason and policy reference.

</Step>
<Step>

### Add members
Set each user `blocked` or `allowed`.

</Step>
<Step>

### Activate
Move the wall to `active`. Blocked users lose access to the matter, including administrators.

</Step>
</Steps>
