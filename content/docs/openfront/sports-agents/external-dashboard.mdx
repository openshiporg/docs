To create a custom Sports Agents dashboard, copy the skill and give it to your LLM. The skill will explain how `features/dashboard` supplies the Keystone administration shell, and where product-specific operator pages would be added under `features/platform`.

After that source orientation, it will ask what you dislike, what should stay, what workflows and users matter, and what the replacement should look and feel like. It then traces the exact routes, feature slices, GraphQL calls, schema, access rules, sessions, and provider boundaries in the supplied Sports Agents codebase before proposing work.

Skill file: [`/skills/openfront-sports-agents-custom-dashboard/SKILL.md`](/skills/openfront-sports-agents-custom-dashboard/SKILL.md)

## Current dashboard pages

All dashboard work happens on the shared shell pages. See [Dashboard overview](/docs/openfront/sports-agents/overview) for the route table.
