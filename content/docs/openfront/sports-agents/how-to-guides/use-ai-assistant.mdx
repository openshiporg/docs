title: Use the AI assistant
description: Ask the sidebar chat to find or change records.
icon: Sparkles
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Configure
Set `OPENROUTER_API_KEY` and `OPENROUTER_MODEL`, or enter your own key in chat settings.
</Step>
<Step>
### Ask
Open the right sidebar and ask, for example, for the blocked todos due this week.
</Step>
<Step>
### Review changes
Write requests run without a confirmation step. Check the record afterwards.
</Step></Steps>
