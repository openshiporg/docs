Openfront Sports Agents is a self-hosted Openfront application built on Next.js, Keystone, GraphQL, Prisma, and PostgreSQL. The source is at [github.com/openshiporg/openfront-sports-agents](https://github.com/openshiporg/openfront-sports-agents).

## What it contains

- **Dashboard** at `/dashboard`: list, create, and item pages for every Keystone list, first-user setup, sign-in, optional sign-up, password reset, and a no-access page.
- **Users and roles:** `User` and `Role` lists with seven permission flags. The first user gets an `Admin` role with every flag on.
- **Task records:** `Todo` (assignee, status, priority, tags, dates, budget, notes, cover image) and `TodoImage` (image library attached to tasks).
- **AI chat:** a dashboard sidebar that calls `/api/completion` through OpenRouter.
- **MCP endpoint:** `/api/mcp-transport/[transport]` exposes generic GraphQL tools using the caller's session.
- **GraphQL API:** `/api/graphql`, served by GraphQL Yoga with the Keystone schema.
- **Image storage:** `Todo.coverImage` and `TodoImage.image` use an S3-compatible bucket.

## Surfaces

| Surface | Path | Purpose |
|---|---|---|
| Landing page | `/` | Links to `/dashboard` and `/api/graphql` |
| Dashboard | `/dashboard` | Home with list counts, plus generic list pages |
| Sign-in | `/dashboard/signin`, `/dashboard/signup`, `/dashboard/reset` | Authentication |
| GraphQL | `/api/graphql` | Keystone CRUD plus `redirectToInit` |
| AI and MCP | `/api/completion`, `/api/mcp-transport/[transport]` | Assistant and tools |

## Ownership and tenancy

One deployment has one database and one set of users. Access is controlled by the role attached to each user:

- A user can always read and edit their own `User` record. Seeing or editing other people needs `canSeeOtherPeople` or `canEditOtherPeople`.
- A `Todo` belongs to the user in `assignedTo`. Users without `canManageAllTodos` only see and change their own.
- Only roles with `canAccessDashboard` can use the dashboard.
