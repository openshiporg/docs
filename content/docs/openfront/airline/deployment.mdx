---
title: Deployment
description: Build, migrate, run the web app, and check health for Openfront Airline.
icon: Rocket
---


Build, migrate as a separate release step, then start:

```bash
npm run build
npm run migrate
npm start
```

`npm run build` does not apply migrations. Back up existing data before migrating.

There is no worker process. Each web process runs the one-minute Stripe Checkout reconcile, and timed expiry happens on requests and the Bookings desk **Refresh** button.

The repository includes `railway.toml` (build, then migrate and `next start`). The README has a Vercel deploy button that asks for `DATABASE_URL`, `SESSION_SECRET`, and four `S3_*` variables. You still need `S3_ENDPOINT` and the rest of the production configuration.

In production `DATABASE_URL` and the five `S3_*` variables must be set (Keystone refuses to start otherwise), `SESSION_SECRET` must be 32+ characters, and `ALLOW_INCOMPLETE_LAUNCH_SETUP=true` keeps public sales closed while you finish setup.

`GET /api/health` returns `{ status: "ok" }`, or 503 when the database is unreachable or `DRAIN_FILE` exists.
