## Stages

`prospecting` → `active_search` → `offer_drafted` → `under_contract` → `inspection` / `financing` → `closed_won`. Open deals can go to `closed_lost`. Use `transitionDealStage`. `transactionType` is `buyer`, `seller`, `tenant`, or `landlord`.

The board shows counts and projected commission by stage.

## Deal detail

| Section | Commands |
| --- | --- |
| Next step and terms | `updateDealNextStepCommand`, `updateDealFinancialTermsCommand` |
| Offers | `createOfferCommand`, `createCounterOfferCommand`, `transitionOfferStatus` |
| Checklist | `createChecklistItemCommand`, `transitionTransactionMilestoneStatus` |
| Documents | `transitionDocumentCommand`, `appendDocumentEvidenceEventCommand` |
| Disclosures | `transitionDisclosureStatus` |
| Inspections | `transitionInspectionCommand` |
| Mortgage, title, escrow | Added on the detail page |

Offers go `draft` → `submitted` → `countered`, `accepted`, `rejected`, or `withdrawn`, with `financingType` of `cash`, `conventional`, `fha`, `va`, or `other`.
