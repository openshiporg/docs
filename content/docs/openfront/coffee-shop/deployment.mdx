Scripts in `package.json`:

| Script | Effect |
|---|---|
| `npm run build` | `keystone build --no-ui && next build`. Does not migrate |
| `npm run migrate` | `prisma migrate deploy` |
| `npm start` | `next start` |
| `npm run lint` | ESLint |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | Unit tests under `features` and `app` with `tsx --test` |

A typical release builds, applies migrations as a separate step against a backed-up database, then starts:

```bash
npm run build
npm run migrate
npm start
```

The included `railway.toml` builds with `keystone build --no-ui && next build` and starts with `npm run migrate && next start`, because the build environment cannot reach an internal database. The README also has a Vercel import button. Either way, provision PostgreSQL, S3-compatible storage, SMTP, and any Stripe credentials yourself. Share the same database, `SESSION_SECRET`, and storage across all app processes.
