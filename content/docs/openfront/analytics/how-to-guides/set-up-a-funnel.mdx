---
title: Set up a funnel
description: Measure drop-off between ordered steps.
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>
### Define goals
Add pageview goals such as `/pricing` and `/checkout/*`, and an event goal such as `Purchase`.
</Step>
<Step>
### Create the funnel
On **Funnels** choose New funnel, name it, and pick the goals in order.
</Step>
<Step>
### Pick a period
Use the period picker. Steps count visits that reached each step in order within one visit.
</Step>
<Step>
### Narrow it
Click a source or country in Overview to add a filter, save it as a segment, and compare.
</Step>
</Steps>
