## Process

One Node process serves the site, dashboard, and GraphQL. `railway.toml` builds with `keystone build --no-ui && next build` and starts with `npm run migrate && next start`.

There are no workers. Lapsed holds, due group cut-offs, queued refunds, and payment-attempt retirements advance on the request that touches them, or when staff press **Refresh** on Front Desk or the Refund queue (`refreshHotelOperations`). Night audit and channel sync are staff buttons, so several web instances can share one database.

<Steps>
<Step>

### Configure

Set `DATABASE_URL`, `SESSION_SECRET`, `HOTEL_DATA_ENCRYPTION_KEY`, `HOTEL_QUOTE_SECRET`, and `NEXT_PUBLIC_SITE_URL` with independent 32+ character secrets. Add the `S3_*` variables for image upload and SMTP for email.

</Step>
<Step>

### Migrate and start

`npm run migrate` then `next start`.

</Step>
<Step>

### Check

Query `{ hotelReadiness }` on `/api/graphql`. It returns `ready` or `not_ready` with a flag for each check.

</Step>
<Step>

### Configure payments

Add Stripe or PayPal at `/dashboard/platform/payment-providers` and point provider webhooks at `/api/payment-webhooks/[providerCode]`.

</Step>
</Steps>

See [Getting started](/docs/openfront/hotel/getting-started) for every variable.
